# TRIMORA – Smart Barber Appointment & Queue Management System

## About the Project

TRIMORA is a web-based Smart Barber Appointment and Queue Management System designed to simplify the process of booking barber appointments and managing shop operations.
The project aims to provide a convenient platform for customers, barbers, and shop administrators.

## Project Features

- Home Page
- Customer Login and Registration Interface
- Appointment Booking Interface
- Customer Dashboard
- Barber Dashboard
- Admin Dashboard
- Service and Barber Selection
- Appointment and Queue Management Interface

## Technology Stack

**Frontend:**
- HTML
- CSS
- JavaScript

**Backend Setup:**
- Node.js
- Express.js
